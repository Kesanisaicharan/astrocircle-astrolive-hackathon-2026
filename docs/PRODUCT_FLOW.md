## Core Growth Loop

**Daily Reading → Compatibility → Share AstroCard → Friend Joins → Friend Gets Reading → Return Tomorrow**

## Business Logic

- **Retention:** daily predictions + streaks
- **Virality:** compatibility + shareable AstroCards
- **Acquisition:** friend invitations
- **Revenue:** premium reports + expert consultations
- **USP:** astrology built around social connection

> The current prototype uses illustrative scores and content. Production implementation would connect real astrology calculations, authentication, analytics, payments, and consultation infrastructure.
